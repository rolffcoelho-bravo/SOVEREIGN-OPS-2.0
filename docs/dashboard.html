G5 — 5-Layer Confirmatory Evaluation Pipeline

Non-parametric statistical testing, family-wise error control, effect-size quantification, bootstrap confidence intervals, and rank concordance — unified in a single auditable pipeline with cryptographic provenance.

L1
Wilcoxon Signed-Rank
Non-parametric paired comparison. Exact enumeration (n≤25), normal approx. with continuity correction (n>25).
L2
Holm–Bonferroni
Step-down FWER correction. Monotonicity enforced across all pairwise comparisons.
L3
Cliff's Delta (δ)
Non-parametric ordinal effect size [-1,+1]. Romano et al. 2006 thresholds: negligible < small < medium < large.
L4
BCa Bootstrap CI
Bias-corrected and accelerated confidence intervals. 10,000 resamples with jackknife acceleration.
L5
Kendall's W
Rank concordance across chronological splits. Stability: weak → moderate → strong → very strong.

G7 — Spectral-Entropic Evidence Synthesis (SEES)

Wavelet packet spectral decomposition, Rényi entropy α-profiling, distribution-free conformal prediction, and Dempster-Shafer evidence theory — fused into a mathematically rigorous anomaly evidence synthesis framework.

P1
Wavelet Packet Spectrum
Haar wavelet packet transform to depth d. Produces 2d spectral energy coefficients per signal segment.
P2
Rényi Entropy α-Spectrum
Generalised entropy Hα(p). Swept across α ∈ {0.5, 1.0, 1.5, 2.0, 3.0} to profile distribution complexity.
P3
Conformal Prediction
Distribution-free calibration. Guarantees finite-sample marginal coverage P(Y ∈ C(X)) ≥ 1−α.
P4
Dempster-Shafer Fusion
Evidence-theoretic combination via Dempster's rule. Mass assignments fused with conflict monitoring.

Extending SEES with sliding-window spectral tracking, CUSUM change-point detection, entropy-signature regime classification via PAM clustering, and regime-conditioned conformal scoring — enabling real-time adaptive anomaly detection across non-stationary operational regimes.

P1
Spectral Tracking
Sliding-window wavelet packet decomposition. Jensen-Shannon divergence monitoring between consecutive spectral snapshots.
P2
CUSUM Change-Point
Page (1954) cumulative sum algorithm. Sequential detection of spectral regime boundaries.
P3
Entropy Regime Classification
PAM clustering in α-divergence space. Rényi entropy signatures clustered into regime archetypes.
P4
Regime-Conditioned Conformal
Per-regime calibrated conformal scoring. Separate calibration sets ensure coverage guarantees under distributional shift.

Key Design Principles

Contract-First
All data flows through immutable Pydantic models (extra="forbid", frozen=True). Canonical JSON serialization with SHA-256 digest for deterministic hashing.
Domain Isolation
Evidence cannot cross domain boundaries — enforced at the type level. No ESA model output ever enters an EDP decision envelope.
Cryptographic Provenance
SHA-256 chains from source bytes through every decision. DOI-pinned datasets with dual-hash verification and acquisition receipts.
Abstention-Aware
The system says "I don't know" when data quality is insufficient. Precision/recall/F1 computed only over non-abstaining subsets; coverage = 1 − abstention_rate.
Confirmatory Statistics
Five-layer non-parametric pipeline: Wilcoxon → Holm-Bonferroni → Cliff's δ → BCa bootstrap CI → Kendall's W concordance. All results immutable and audit-ready.
Spectral-Entropic Synthesis
Wavelet packet spectral decomposition → Rényi entropy α-profiling → conformal prediction → Dempster-Shafer fusion. Rigorous uncertainty quantification with conflict detection.
Adaptive Regime Detection
Sliding-window spectral tracking → CUSUM change-point → PAM entropy clustering → regime-conditioned conformal scoring. Real-time adaptation to non-stationary operational regimes.
