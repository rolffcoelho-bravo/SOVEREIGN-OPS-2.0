G5 — 5-Layer Confirmatory Evaluation Pipeline

A novel combination of non-parametric statistical testing, family-wise error control, effect-size quantification, bootstrap confidence intervals, and rank concordance — unified in a single auditable pipeline with cryptographic provenance.

L1
Wilcoxon Signed-Rank
Non-parametric paired comparison.
Exact enumeration (n ≤ 25), normal approximation with continuity correction (n > 25).
→
L2
Holm–Bonferroni
Step-down FWER correction.
Monotonicity enforced across all pairwise comparisons.
→
L3
Cliff's Delta (δ)
Non-parametric ordinal effect size [-1,+1].
Romano et al. 2006 thresholds: negligible < 0.147 < small < 0.33 < medium < 0.474 < large.
→
L4
BCa Bootstrap CI
Bias-corrected and accelerated confidence intervals.
10,000 resamples with jackknife acceleration factor.
→
L5
Kendall's W
Rank concordance across chronological splits.
Stability: < 0.3 weak, < 0.5 moderate, < 0.7 strong, ≥ 0.7 very strong.

Key Design Principles

Contract-First
All data flows through immutable Pydantic models (extra="forbid", frozen=True). Canonical JSON serialization with SHA-256 digest for deterministic hashing.
Domain Isolation
Evidence cannot cross domain boundaries — enforced at the type level. No ESA model output ever enters an EDP decision envelope.
Cryptographic Provenance
SHA-256 chains from source bytes through every decision. DOI-pinned datasets with dual-hash verification and acquisition audit receipts.
Abstention-Aware
The system says "I don't know" when data quality is insufficient. Precision/recall/F1 computed only over non-abstaining subsets; coverage = 1 − abstention_rate.
Confirmatory Statistics
Five-layer non-parametric pipeline: Wilcoxon signed-rank → Holm-Bonferroni → Cliff's δ → BCa bootstrap CI → Kendall's W concordance. All results immutable and audit-ready.
